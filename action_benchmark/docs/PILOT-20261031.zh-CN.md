两边输入不同，测试目标是验证规范接入与共同评分入口，不能将其解释为同输入条件下的算法对照实验。

## 执行情况

1. 为 Argus 准备仅含目标 episode 1 的独立 job。
2. 为 alignment 创建独立输入副本，只保留 episode 0 的人工标注。
   复制两个 episode 的 Parquet 时删除含 `annotation` 的列；原视频只读引用。
   SDK 要求场景对象具有整数 ID，而原数据未提供，所以只在副本中补齐 ID；没有改动动作或边界。
3. alignment 的转换、DINO/物理边界对齐和打包完成。
4. Argus 发起 1 次模型请求，返回 401；没有模型标注输出。
5. alignment 对 6 个不同片段分别发起请求，均返回 401；SDK 的报告为 `partial`，`annotation_count=0`、`failure_count=6`。
   保留的片段来自已完成的边界对齐及 SDK 部分结果处理，**不是成功的 VLM 标注**。
6. 没有继续重试，没有用失败结果生成正式对比成绩。

初次本地尝试中，Argus 的过度保守预算检查拒绝了请求，alignment 的场景对象 ID 校验也拒绝了输入；这两次都没有发出模型请求。
随后修正的是调用前的预算估计和输入格式适配，不是针对模型回复的付费重试。

实际共收到 7 次 HTTP 401，均无 token usage，也无可验证的费用回执。不能用本地预留金额充当实际扣费；账单以服务商控制台为准。

## 新增调用入口

- [dashscope_pilot.py](dashscope_pilot.py)：有限范围的 DashScope 测试传输，不是对原有 harness 所有 provider 路径的全面替换。
  固定官方北京地址，仅从 `DASHSCOPE_API_KEY` 读取密钥；不跟随重定向，不自动重试；请求前保存无密钥的调度记录。
- [pilot_alignment.py](pilot_alignment.py)：使用 alignment SDK 的转换、对齐、打包和标注阶段，不修改另一个仓库的源码。
  支持将结果转换到当前 benchmark 格式，部分结果单独命名。
- 加入了预算拒绝、超时结果保留和鉴权失败停止后续请求的离线测试。

本次实际运行时，SDK 会继续处理其他片段，因此产生了 6 次独立的 401 请求。
之后已加上鉴权失败熔断：后续运行中第一条 401/403 后，其他片段不会再向服务端发送请求。

预算估计依据公开价格和图像 token 上限，采用高价格档预留，且显式关闭高分辨率图像开关：
[模型价格](https://help.aliyun.com/zh/model-studio/qwen3-6-plus)、
[视觉输入文档](https://help.aliyun.com/en/model-studio/vision)。
账户优惠、实际 usage 和账单可能与预留金额不同。
